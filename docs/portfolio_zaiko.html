Portfolio — Case Study

やさしい在庫管理

小規模店舗・B型事業所向け在庫管理Webアプリ

商品・在庫・入出荷履歴を一元管理し、在庫不足や記録漏れを減らすことを目指したシンプルな業務支援アプリです。

Role企画・UI設計・フロントエンド実装・DB連携
StackReact / JavaScript / Supabase / Tailwind CSS
Target個人事業主・就労継続支援B型事業所を想定
Problem

解決したい課題

Excelや紙での在庫管理には、次の3つの困りごとがある。

1

確認に手間がかかる

在庫を確認するたびに、紙やExcelファイルを探す必要がある。

2

記録漏れが起きやすい

忙しい時間帯に入荷・出荷の記録を付け忘れ、在庫数が合わなくなる。

3

欠品に気づけない

発注タイミングを逃して欠品が発生し、販売機会を失う。

Concept

コンセプト・対象ユーザー

「Excelより簡単、専門ツールより手軽」な在庫管理アプリ

入力項目を最小限に絞り、考えなければいけないことの数そのものを減らす。パソコン操作に不慣れな人でも迷いにくいUIを目指した。

Main

個人事業主

個人経営の雑貨店オーナーなど。忙しい接客の合間でも、パソコン操作が得意でなくても素早く在庫を確認できる。

Extension

就労継続支援B型事業所

管理者・スタッフ・利用者の3ロールに対応。利用者は棚卸し専用のシンプルな画面だけを操作する。

Features

主な機能

やることを4つに絞り、それぞれの操作を最短で終えられるようにした。

1

在庫一覧

商品名・カテゴリ・在庫数を一覧表示。発注点を下回った商品は赤色で強調される。

2

入出荷記録

入荷／出荷を記録すると在庫数が自動更新され、履歴として残る。

3

在庫不足の通知・絞り込み

「在庫切れ」「在庫少」をワンタップで絞り込み、不足商品をすぐ見つけられる。

Design Strength

役割に合わせた設計

管理者・スタッフ・利用者で、できる操作と見える画面をそれぞれ変えている。利用者ごとに必要な操作だけを表示し、誤操作を防ぎながら作業しやすい画面構成にした。

管理者
全機能＋店舗情報編集＋権限管理
スタッフ
商品登録・編集・削除、入出荷記録
利用者
棚卸し（実数の記入）のみ
管理者視点 — 削除・単価まで表示
スタッフ視点 — 削除・単価は非表示
棚卸し専用画面（利用者向け） — 1件ずつ数えて入力するだけ
棚卸し結果一覧 — 登録数とのズレを自動チェック

福祉系事業所での業務経験がある訓練校受講者への聞き取りをもとに、役割に応じた操作範囲を設計した。

Tech

技術と設計上の工夫

技術役割
React / JavaScript (JSX)UI構築・実装言語
React Router画面遷移（SPA）
Tailwind CSSデザイン
Supabaseデータ保存（クラウドDB）
React を選んだ理由画面を部品（コンポーネント）単位に分け、再利用・修正しやすくするため。
Supabase を選んだ理由複数端末でのデータ共有と、管理者・スタッフ・利用者の認証・権限管理に対応するため。
画面間の在庫表示のずれを解消Contextで在庫データを1か所にまとめ、どの画面でも同じ状態を参照できるようにした。
在庫更新と履歴記録の不整合を解消在庫の更新と入出荷履歴の記録を一連の処理としてまとめ、データの整合性を保つようにした。
Iteration — 最も伝えたいこと

開発中に改善したこと

最初の設計に固執せず、実際の運用を想定しながら要件と技術選定を見直した。

個人事業主向け

→
最終版での改善
